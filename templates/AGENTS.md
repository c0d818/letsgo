# Stitches Project Rules

This project is managed by Stitches.

Before broad implementation work, read:

- `.opencode/skills/stitches-workflow/SKILL.md`
- `.opencode/skills/stitches-spec/SKILL.md`
- `openspec/project.md`

Use the Stitches command flow:

1. `/stitch-explore`
2. `/stitch-propose`
3. `/stitch-apply`
4. `/stitch-review`
5. `/stitch-ship`

Small, clearly safe edits may skip proposal only when the requested change is
local, reversible, and does not alter behavior contracts.
